# ДЗ 1
Реализация decoder-only языковой модели в двух Python-файлах. В качестве
ориентиров использованы схема из лекции `q2.pdf` и пример `gqa_sdpa.py` из
чата курса. Модель инициализируется случайно; готовые веса Llama не загружаются.

## модель
`model.py` содержит embedding, четыре decoder-блока и выходной слой. В каждом
блоке стоят RMSNorm, каузальный attention с RoPE, SwiGLU и residual connections.
В GQA восемь голов запросов используют две головы ключей и значений. Attention
вычисляется через `torch.nn.functional.scaled_dot_product_attention` с
`is_causal=True` и `enable_gqa=True`.

Параметры модели в `model_config.json`: размерность 256, четыре блока,
контекст до 128 токенов. 3148032 параметров.

## запуск
Python 3.12. локальный запуск на RTX 3070 Ti Laptop
PyTorch с CUDA 12.8:

```powershell
python -m pip install --extra-index-url https://download.pytorch.org/whl/cu128 -r requirements.txt
python train.py --steps 100
```

Скрипт выбирает CUDA, если она доступна, иначе CPU. После запуска рядом с кодом
появятся `model_config.json`, `run_config.json`, `loss.csv`,
`training_loss.png` и `sample.txt`.

Для выбора корпуса текста `corpus.txt`:

```powershell
python train.py --text-file corpus.txt --output-dir normal_text_run --prompt "В субботу " --steps 200
```

Этот запуск сохраняет результаты в отдельную папку и не перезаписывает базовый
график.

## тест
`train.py` обучает модель предсказывать следующий байт UTF-8. Словарь из 256
байтов позволяет обойтись без отдельного токенизатора; при этом русская буква
занимает несколько токенов. Набор состоит из четырёх коротких строк,
повторённых 16 раз. Из него получаются 87 перекрывающихся примеров длиной 64.

За 100 шагов средний лосс на этом же наборе снизился с 5,7498 до
0,0446, а точность предсказания следующего байта выросла до 98,3%.

Запуск на большем тексте без повторения строк (950 символов)
За 200 шагов loss снизился с 5,6925 до 0,0419, точность 98,4%.
График и числа находятся в `normal_text_run`. Продолжение из короткой подсказки всё ещё быстро сбивается.
